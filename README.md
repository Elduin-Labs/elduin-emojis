# Elduin Emojis

Type a code in Minecraft chat and a little picture of my face pops up. There are
nine of them, in different colors. Type `/emojis` in chat to see them all.

| code | face |
|---|---|
| `:elduin:` | my normal face |
| `:red:` `:orange:` `:yellow:` | red, orange, yellow |
| `:green:` `:aqua:` `:blue:` | green, aqua, blue |
| `:purple:` `:pink:` | purple, pink |

Only you need the mod to see the faces. Friends without it see the code as text.

Fabric, for Minecraft 1.21.11 and 26.2. Needs Fabric API.

Made by Elduin, with Claude.
